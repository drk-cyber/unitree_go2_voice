# Go2 对话台

电脑上的本地网页，用于查看 Go2 EDU 语音对话。USB 麦克风仍插在狗的算力板上。网页按人和机器狗显示识别文字、播报台词和电脑接收时间。

## 在电脑上看演示

在仓库根目录打开 Windows PowerShell，执行以下命令。

```powershell
Set-Location .\go2_voice_frontend
python server.py
```

浏览器打开 `http://127.0.0.1:8765/`。页面用几句模拟台词展示医院回收交接场景，可以点「重播演示」。没有实机或网线也能预览。

## 接入实机

1. 让电脑能通过 SSH 连到算力板 `192.168.123.18`，确认板上的 USB 麦克风就绪。确认现有 `go2-voice` 服务已正常运行，日志中有“可以说话了”。如果服务之前停过、自启关过，先在确定适合实机测试时按原项目的服务说明启动。完整语音服务可能让狗起身。
2. 如果演示服务正在运行，在对应的 PowerShell 里按 `Ctrl+C`。在 `go2_voice_frontend` 目录执行以下命令。

   ```powershell
   python server.py --live
   ```

3. 在启动它的 PowerShell 窗口完成 SSH 登录。如果系统要求确认 SSH 主机身份，请按平时连接该板子的方式核对。如果需要输入密码，密码在终端输入。
4. 浏览器打开 `http://127.0.0.1:8765/`，看到「日志已接入」后，对狗身上的麦克风说“小狗，打招呼”。板上的语音程序更新到含回收口令的版本后，也可以说“小狗，请回收医疗废物”，网页应显示这句话和狗的回复“好的，我去执行任务”。回收口令只触发播报。

更换算力板的地址或账号可以用 `python server.py --live --target unitree@192.168.123.18`。端口冲突时可以指定 `--port 8766`，然后打开对应地址。

部署或更新狗上的语音服务见[板载语音说明](../BOARD_V8.md)和[后台服务说明](../BOARD_SERVICE.md)。电脑端和算力板的程序分别运行。

## 数据范围

- 实机模式通过现有 SSH 账号读取 `go2-voice` 的新增日志。需要该账号已有 `journalctl -u go2-voice` 的读取权限。网页显示「日志已接入」表示已登录、服务在运行且能读到日志。是否收到新对话，以说话后实际出现的文字为准。
- 页面用“识别结果”和“发送播报”配对。有播报的对话才显示，未唤醒的旁白和单纯识别但没回复的内容通常不会出现。播报文字表示程序已将音频加入播放队列，声音是否实际放出仍可现场确认。日志配对适合当前免回车、逐句回应的流程。
- 网页只监听本机，显示当次启动后接收到的最近 120 条消息。前端项目不另写录音或对话文件。板上的 systemd 日志仍按原程序和系统设置记录。演示阶段请用模拟台词，避免采集患者姓名、病历等信息。
- 医疗废物分类、任务派发和导航还没有接入。演示台词仅用于表达交接页面的形态。

`server.py` 提供本地页面并读取语音日志，`web/` 放 HTML、样式和页面逻辑。电脑端只需 Python 3 和 Windows OpenSSH，界面资源随项目提供。
